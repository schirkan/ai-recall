AppReader-Plugin-System

Der Vertrag ist IAppReader aus AiRecall.AppReader.Base. Die Registry lädt alle DLLs aus AppReaderConfig.PluginPath, instanziiert sie und indexiert sie nach Prozessname; der erste Treffer gewinnt. Das Ergebnis wird per AppReaderResult.ToContentRecord() an den Conversion Worker übergeben.
